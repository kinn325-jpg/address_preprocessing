# 실제 배송 자료 처리 결과 요약

> 이 문서에는 개인정보가 없는 **집계 숫자만** 담았습니다.

## 해석

- 송장 3건 중 1건 이상은 표기 오류가 있었고, 규칙으로 자동 수정할 수 있었습니다.
- 확인필요의 대부분(6,100건)은 **도로명 없이 건물명만 적힌 주소**였습니다.
  "롯데월드타워 25층"처럼 사람은 바로 알아보지만, 규칙으로는 어느 도로인지 알 수 없는 경우입니다.
