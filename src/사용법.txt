[배송 송장 주소 자동 정제 프로그램 사용법]

1. 새 엑셀 파일을 원본 엑셀 폴더에 넣습니다.
2. 이 폴더의 '실행.bat' 을 더블클릭합니다.
3. 원본 폴더 안 '주소정제_결과' 폴더에 '<원본파일명>_정제.xlsx' 가 생깁니다. (원본은 그대로)
   - 노란 칸: 자동 수정된 주소 / M열 '수정내역'에 무엇을 고쳤는지 기록
   - 빨간 칸(N열 '확인필요'): 자동으로 고칠 수 없어 사람이 봐야 하는 건
4. '_주소정제_결과보고.xlsx' 에 전체 요약 / 확인필요 목록 / 수정내역 이 모여 있습니다.

[자동 수정 항목]
- 35자에서 잘린 단어 복원 (Yeongdong-daer → Yeongdong-daero, Gyeonggi-d → Gyeonggi-do, 268 Son → 268 Songpa-daero)
  * 같은 우편번호에서 쓰인 도로명을 기준으로 복원
- Address1 끝 + Address2 앞으로 끊긴 단어 연결 (GAN + GNAM-GU → GANGNAM-GU)
- 도로명 오타/띄어쓰기 (Samsungro → Samseong-ro, Taeheran-ro → Teheran-ro, Sonpa daero → Songpa-daero)
- 행정구역 표기 (Kangnam-ku → Gangnam-gu, Sungnam city → Seongnam-si, Gyeonggido → Gyeonggi-do)
- 깨진 문자 '?' → 공백, 엑셀 오류값 '#NAME?' 삭제
- Address1/Address2 중복 제거
- 우편번호 칸이 비었으면 주소 속 우편번호로 채움, 우편번호 앞자리 0 표시(05854)

[확인필요로 표시되는 경우]
- 한글 깨짐(???), #NAME? 로 원본 소실, 주소 끝 잘림 복원 불가
- 도로명/지번 없음(건물명·아파트명만), 번지 없음, 우편번호 없음
- 구/시 ↔ 우편번호 불일치, 도로명 ↔ 우편번호 불일치 의심, 주소 속 우편번호 ↔ 우편번호칸 불일치
- NA 시트(배송구역 미지정)

[참고]
- '도로명사전.json' 은 프로그램이 데이터에서 학습한 도로명 기록입니다. 새 파일이 들어오면 자동으로 추가 학습합니다.
  처음부터 다시 학습하려면 이 파일을 지우거나 '실행.bat --relearn' 으로 실행하세요.
- 자동으로 못 잡는 표기는 '수동사전.json' 의 '도로명_별칭' 에 "틀린표기": "올바른표기" 로 추가하세요.
- Python 3.8 이상 필요 (openpyxl 은 실행.bat 이 자동 설치)
